# Sample essays for seed_blog tests

This README must be ignored by the seed command.

essay allow-list. They are small samples, not the real essays (those live in the
essay source directory mounted at `/essays`). Files outside `ESSAY_ALLOW_LIST`
(for example a hypothetical `bria.md`) must not seed.
